# Favicon

- `favicon.svg`: merket, for moderne nettlesere. `<link rel="icon" href="/favicon.svg" type="image/svg+xml">`
- `favicon-32.png`, `favicon-16.png`: reserve. `<link rel="icon" href="/favicon-32.png" sizes="32x32">`
- `apple-touch-icon-180.png`: hvit bakgrunn. `<link rel="apple-touch-icon" href="/apple-touch-icon-180.png">`
- `icon-192.png`, `icon-512.png`: web-manifest.

Bare lys utgave. Nettsidene, CRM og kundeportalen har ikke mørk modus.
